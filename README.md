# AI 写稿直发公众号草稿箱

> 篝火出品 · 收录于篝火 App 应用区

写稿、排版后推到草稿箱，走公众号官方接口

![界面截图](docs/screenshot.png)

## 下载

到 [Releases](https://github.com/campfire-code/wechat-draft-publisher/releases/latest) 下载对应安装包：

| 电脑 | 文件 |
|---|---|
| Windows 10 / 11 | `wechat-draft-publisher_版本号_windows-x64-setup.exe` |
| Mac（Apple 芯片） | `wechat-draft-publisher_版本号_mac-arm64.dmg` |
| Mac（Intel 芯片） | `wechat-draft-publisher_版本号_mac-x64.dmg` |

第一次打开：
- **Windows**：如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
- **Mac**：如果提示「无法验证开发者」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」。

## 怎么用

**第一次使用：两项设置**
1. 顶部「设置」里填大模型的接口地址、密钥和模型名（兼容 OpenAI 接口格式，DeepSeek、通义千问、Kimi 等都可以）。不用 AI 写稿、只排版的话可以不填。
2. 「写稿」页右下角展开「公众号设置」，填公众号的 **AppID** 和 **AppSecret**（在「微信开发者平台 → 扫码登录 → 我的业务 → 你的公众号」里查看，忘记了只能重置）。
   **还要在同一页面的「API IP 白名单」里加入本机的公网 IP**，否则会提示「本机公网 IP 不在公众号的 IP 白名单里」——提示里会写出微信看到的 IP，照着加进去即可。点「保存并测试连接」显示「连接成功」就说明三项都没问题。
   AppID、AppSecret 只保存在这台电脑上，不会上传到别处。

**写稿**
1. 展开「AI 写稿」，填主题，可选填提纲（每行一个要点）和参考资料（AI 只用资料里的事实，不会编数据），选风格和篇幅，点「生成文章」。
2. 生成的标题、摘要、正文会填进下面的编辑区，可以直接改。标题最多 32 字、作者 16 字、摘要 120 字，超出时计数变红。
3. 正文是 Markdown：`## 小标题`、`**加粗**`、`- 列表`、`> 引用`、代码块都支持。点「插入本机图片」可以插入电脑上的图片；网络图片写 `![](https://…)`。

**排版与发布**
1. 右侧实时预览公众号里的样子，点上方的主题（默认、橙心、彩虹、青金、少数派风、麦穗黄、淡紫、薄荷绿）切换样式。文章里的外部链接会自动转成文末脚注（公众号不允许正文外链）。
2. 「复制富文本」后到公众号编辑器里粘贴，样式保留；本机图片需要在编辑器里重新上传。
3. 「导出 HTML」保存到「下载/AI 写稿直发公众号草稿箱」文件夹。
4. 「存到草稿箱」：自动把正文图片上传到微信（不是 JPG/PNG 或超过 1MB 的会自动转成 JPG 并压缩），上传封面，再新建一篇草稿。封面可以点「选择图片」指定；不指定时用正文第一张图，没有图就按标题自动生成一张。完成后到公众号后台的草稿箱检查、发表。

**注意**
- 走的是微信公众号官方接口（获取 access_token、上传图文消息内的图片、新增永久素材、新增草稿），不模拟登录。未认证的订阅号可能没有草稿接口权限，会提示「没有调用该接口的权限」。
- 每次存草稿会新增一个永久图片素材（封面），公众号素材库图片上限 10 万张。

## 验收用例

没有真实公众号时，下面带「需公众号」的用例列入待联调清单；其余用例可以直接验证。

| 操作 | 应得到 |
|---|---|
| 首次打开 | 编辑区是示例文章「小店做会员，先别急着送折扣」，右侧显示公众号样式预览，与 `samples/示例导出-默认主题.html` 的样式一致 |
| 依次点 8 个主题 | 预览的标题、引用、列表样式随之变化，左侧内容不变 |
| 设置好大模型后，按 `samples/示例写稿要求.txt` 填主题、提纲、参考资料，点「生成文章」 | 30 秒内标题、摘要、正文被替换为新文章；正文有 3～6 个「## 」小标题；提示「已生成「标题」」 |
| 标题改成 33 个字 | 计数显示 33/32 并变红；点「存到草稿箱」提示「标题超过 32 个字（现在 33 个）」，不发请求 |
| 点「复制富文本」，粘贴到公众号编辑器（或 Word） | 出现带样式的文章，小标题、加粗、引用样式与预览一致 |
| 点「导出 HTML」 | 下载目录的「AI 写稿直发公众号草稿箱」里出现 `标题.html`，浏览器打开后与预览一致 |
| 公众号设置里 AppID 填 `wx0000000000000000`、AppSecret 随便填，点「保存并测试连接」 | 提示「AppID 不对，请检查是否填错（注意大小写和多余空格）」 |
| （需公众号）填正确的 AppID / AppSecret，但没加 IP 白名单，点「保存并测试连接」 | 提示「本机公网 IP 不在公众号的 IP 白名单里（微信看到的 IP 是 x.x.x.x）……」 |
| （需公众号）加好白名单后，用示例文章（插入一张本机 PNG）点「存到草稿箱」 | 按钮依次显示「正在连接公众号… / 正在上传正文图片 1/1… / 正在上传封面… / 正在存入草稿箱…」，最后提示「已存入草稿箱（上传了 1 张正文图片，使用正文第一张图作封面）」；公众号后台草稿箱出现这篇文章，排版与预览一致，图片正常显示 |

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
